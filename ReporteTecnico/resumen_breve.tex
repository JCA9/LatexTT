    \textbf{RESUMEN}
\end{center}

\noindent\justifying
El presente Trabajo Terminal describe el diseño, análisis y desarrollo de un sistema integral para la gestión de finanzas personales, compuesto por una aplicación móvil y una plataforma web. El sistema permite registrar ingresos y gastos de forma automatizada mediante Reconocimiento Óptico de Caracteres (OCR), extrayendo información de tickets de compra físicos o digitales.

La solución emplea una arquitectura cliente-servidor en tres capas: backend en Node.js, frontend web en Next.js y aplicación móvil en Flutter, con almacenamiento en MySQL e intercambio de datos mediante una API REST. La categorización automática de gastos aplica reglas heurísticas basadas en el modelo de sobres de Dave Ramsey, presentando resultados mediante tableros interactivos con gráficos dinámicos.

El proyecto atiende una problemática identificada en la población mexicana: según la Encuesta Nacional sobre Salud Financiera (ENSAFI) 2023, solo el 53.2\,\% de los ciudadanos lleva algún tipo de registro de sus gastos. La solución busca fomentar hábitos financieros saludables mediante tecnología accesible orientada a jóvenes y adultos sin conocimientos contables avanzados.
